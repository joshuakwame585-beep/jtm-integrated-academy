# JOSH TECH MEDIA (JTM) — Integrated Academy V5

A responsive JTM public website plus a student/admin LMS portal starter. See **SETUP.md** for preview, Supabase setup, admin activation, Netlify deployment and important limitations.

Start with `index.html` for the public website and `lms.html` for the academy portal. The portal includes a local demo mode so you can explore the student and admin interfaces before connecting Supabase.
